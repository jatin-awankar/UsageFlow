# Issue tracker: Local Markdown

Specs and issues live under `.scratch/<feature-slug>/` in this repository.

- Publish a spec as `.scratch/<feature-slug>/spec.md`.
- Put implementation tickets, when requested, in `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, numbered from `01`.
- Record triage state with a `Status:` line near the top of each file, using `docs/agents/triage-labels.md`.
- Append discussion under `## Comments` rather than replacing prior decisions.
